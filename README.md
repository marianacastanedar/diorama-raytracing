# Diorama Marino - Raytracing

Proyecto 2 de gráficas por computadora. Raytracer por CPU sobre un diorama
marino de cubos, con refracción y reflexión en el agua.

## Build

    cargo build --release

## Run

    cargo run --release

## Controles

| Tecla     | Acción           |
|-----------|------------------|
| Flechas   | Orbitar cámara   |
| + / -     | Zoom             |
| Esc       | Salir            |
